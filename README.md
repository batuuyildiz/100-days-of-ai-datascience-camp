# 100-days-of-ai-datascience-camp

**By following the Udemy course “Data Science and Machine Learning 2025: 100 Days Bootcamp” by Atıl Samancıoğlu, this repo documents my daily journey to master AI & Data Science from scratch.** The course features over **50 real-world datasets**, hands-on coding examples, and in-depth theory explanations to ensure both practice and understanding.  
[Udemy.com](https://www.udemy.com/course/yapay-zeka-100-gunluk-kamp/)

---

## 📚 What's in the Curriculum?

The course covers a wide range of topics, including but not limited to:
- Python programming (beginner to advanced)
- Statistics & Mathematics for Data Science
- Data Analysis & Visualization (NumPy, Pandas, Matplotlib, Seaborn)
- SQL and its integration with Python
- Machine Learning (Regression, Classification, Clustering)
- Advanced ML (Ensemble Methods, Boosting, PCA, etc.)
- Real-world projects and Kaggle exercises

## 🚀 How to Use This Repo
- Each folder is named as `dayXXX` (e.g., `day001`, `day002`, …).  
- Inside each folder you’ll find Jupyter Notebooks (`.ipynb`) with exercises, notes, and assignments.  
- Dependencies are listed in `requirements.txt`.
